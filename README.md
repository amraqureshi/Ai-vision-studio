# 🚀 AI Vision Studio

> A full-stack AI-powered object detection platform built with **React, TypeScript, FastAPI, and YOLOv11**.

AI Vision Studio is a computer vision web application that allows users to upload images and detect objects using a YOLOv11 model. The project demonstrates the integration of an AI model with a modern React frontend and a FastAPI backend.

---

## 📌 Overview

AI Vision Studio provides a simple interface for image-based object detection.

The application follows this workflow:

```text
User uploads image
        ↓
React Frontend
        ↓
FastAPI Backend
        ↓
YOLOv11 Object Detection
        ↓
Detected Objects + Confidence Scores
        ↓
Results displayed in Frontend
